# AI StudyMate Frontend

This directory contains the React and Vite frontend for AI StudyMate. See the [root README](../README.md) for features, architecture, backend setup, environment variables, and project limitations.

## Commands

```powershell
npm install
npm run dev
npm test
npm run build
npm run lint
```

The development client uses `http://localhost:8000/api/v1` by default. Set `VITE_API_BASE_URL` (or `VITE_API_URL`) when the backend runs elsewhere.
